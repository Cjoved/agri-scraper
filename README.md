# OpenStatv2

Agri-price scrapers (OpenSTAT/PSA, PhilRice, PinoyRice) and CPT data processing.

**Run:** `python main.py` (configure via `.env`: PHILRICE, PHILRICE_NEWS, PINOYRICE, OPENSTAT)

**Documentation:** [docs/](docs/) — PROJECT_STRUCTURE.md, README (full), NEP data sources, etc.

**Docker:** `docker-compose.yml` in project root.
